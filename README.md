# SkillSpring screenshot-style multi-service affiliate website

Files included:
- `index.html` — Home page with hero, three service cards, trust strip, growth section and affiliate disclosure
- `services.html` — Writing, design/video editing, and website development
- `courses.html` — course/tool placeholders to replace with approved affiliate offers
- `about.html` — site purpose and affiliate explanation
- `contact.html` — contact details placeholder
- `styles.css` — responsive desktop/mobile styles
- `script.js` — mobile navigation and footer year

Before publishing:
1. Add your own public contact email and official social links.
2. Replace the example resource cards with real offers you have verified.
3. Use only affiliate URLs issued by programs that approved you. No real affiliate URLs are invented here.
4. Check provider details, current prices, terms and every link.
5. Keep the affiliate disclosure visible and test the pages on Android.

GitHub Pages:
1. Extract this ZIP.
2. Upload the files into your repository's root folder.
3. Go to Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/(root)`, then save.
5. Test Home, Services, Top Courses, About and Contact.

This is a static starter site. It does not process payments or verify affiliate approvals.
